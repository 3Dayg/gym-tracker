# Follow along

Follow along is a second presentation of the same live session — not a second data model. Use it when you already know the plan and want one card at a time instead of a scrolling list.

The list remains available as **All sets**. Switching mid-workout never invents or drops sets. `SetEntry` and `SessionTimer` stay the source of truth.

## Mental model

**As planned unless you intervene.** Targets already on the set (plan + last-used weight) are what get saved when you tap **Done**. Edit is always available. Auto-complete of a lift is never allowed.

## Starting

- On a plan preview: **Follow along** (one card) or **Start Workout** (today’s list).
- During a live workout: **Follow along** in the toolbar. **All sets** drops back to the list.

## What you see

- **Strength:** one large card — name, set i/n, weight/reps, **Done / Skip / Fail**. Rest ending does **not** mark the next set complete.
- **Timed (boxing):** current round on the card. **Start** begins work; at zero the round is logged and rest begins.
- **Rest:** full-screen countdown; at zero the next card appears and the phone haptics. Skip or −15/+15 still work.
- **Cardio:** one block card; **Done** when you get off the machine. Rest does not start.

## Always available

Edit this set, Skip, Fail, Add set / Add exercise, **All sets**, Finish / Discard.

## Tap budget

A consistent strength session is **one primary tap per set** (Done), plus optional edits.

## Do not expect

Estimated work-duration for lifts, auto-fail, or history you cannot open and change afterward.

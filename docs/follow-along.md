# Follow along

Follow along is the live workout: one card at a time on the same `SetEntry` rows and `SessionTimer`. There is no second data model.

## Mental model

**As planned unless you intervene.** Targets already on the set (plan + last-used weight) are what get saved when you tap **Done**. Edit is always available. Auto-complete of a lift is never allowed.

A busy machine does not mean Skip. Open **Exercises** to jump to any other pending exercise and come back — nothing is skipped.

## Starting

- On a plan preview: **Start Workout**. The card is what you train from.
- Quick Start opens the same card, empty, until you add an exercise.

## What you see

- **Strength:** one large card — name, set i/n, weight/reps, **Done / Skip / Fail**. Rest ending does **not** mark the next set complete.
- **Timed (boxing):** current round on the card. **Start** shows 3-2-1 so you can get set, then work begins; at zero the round is logged and rest begins. **Done** still logs early.
- **Rest:** full-screen countdown; at zero the next card appears and the phone haptics. Skip or −15/+15 still work.
- **Cardio:** one set card. Set time by hand, or **Start** the same work countdown as timed rounds. At zero the set is logged; rest does **not** start. **Done** still logs when you get off the machine.

## Switching exercises

- **Exercises** — every exercise with logged/total and a check when a row is fully logged. Tap a pending one to jump the card there. Tap a finished one to edit a past row.
- When the exercise you jumped to is fully logged, the card returns to the first unfinished exercise in plan order.

## Always available

Skip, Fail, Add set / Add exercise, **Exercises**, Finish / Discard.

## Tap budget

A consistent strength session is **one primary tap per set** (Done), plus optional edits. Use **Exercises** when the floor does not match the plan.

## Do not expect

Estimated work-duration for lifts, auto-fail, or history you cannot open and change afterward.

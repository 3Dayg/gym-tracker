# The exercise library

The **Exercises** tab lists every exercise you can use in plans and workouts. The app ships with about 60 common exercises covering chest, back, shoulders, arms, legs, glutes, core, and cardio.

## Finding an exercise

- **Search** by name using the search bar.
- **Filter** by muscle group with the funnel icon in the top-left.
- If nothing matches, **Clear Filters** restores the list, or **Add Exercise** creates a custom one.

The same search and filter are available inside the exercise picker whenever you add an exercise to a plan or a running workout. After you have finished a workout, **Recent** lists those lifts at the top so you do not have to search again.

## Exercise details

Tap an exercise to see its muscle group, equipment, notes, and your ten most recent logged workouts with it — handy for checking what you lifted last time.

## Custom exercises

Tap **+** in the top-right to add your own exercise:

- **Name** — required.
- **Muscle group** and **equipment** — used for filtering.
- **Type** — how the exercise is logged:
  - **Strength** — reps and weight (bench press, rows).
  - **Timed** — duration only (plank, jump rope, bag rounds).
  - **Cardio** — time, speed, incline, and distance (treadmill, bike, rower).
- **Notes** — optional, e.g. machine settings or form cues.

Custom exercises are marked with a "Custom" badge and work exactly like built-in ones.

## Editing and deleting

- Custom exercises can be edited from their detail screen (**Edit** button) and deleted by swiping them left in the list. Built-in exercises never show a delete action.
- Names must be unique (ignoring case). The app warns if you reuse a name.
- **Type** locks after the exercise has been logged so old workouts stay readable.
- Deleting a custom exercise asks first and lists any plans that use it. Those plan rows are removed so a workout cannot silently skip them. Past workouts keep the exercise name.
